IEP PANORAMA

Automação inteligente de produção audiovisual, organização de conteúdos digitais e integração entre ferramentas de criação.

Sobre o projeto

O IEP Panorama é um projeto independente de automação de produção audiovisual, voltado à criação e organização de conteúdos digitais.

Seu objetivo é integrar diferentes ferramentas tecnológicas para apoiar atividades como pesquisa, elaboração de roteiros, processamento de imagens, produção de áudio, edição de vídeos e organização dos arquivos utilizados.

Integração com o Google Drive

O aplicativo IEP Panorama - n8n Local utiliza a API oficial do Google Drive para acessar arquivos e pastas mediante autorização expressa do titular da conta Google.

Essa integração permite organizar arquivos, consultar conteúdos, criar pastas e transferir materiais utilizados nos processos de automação audiovisual.

O acesso é realizado por meio do protocolo OAuth 2.0 do Google e depende das permissões concedidas pelo usuário.

Utilização dos dados

Os dados acessados pela integração são utilizados para executar as operações autorizadas pelo usuário e necessárias aos workflows configurados.

Informações adicionais sobre coleta, acesso, armazenamento, compartilhamento, retenção e exclusão de dados estão disponíveis na nossa Política de Privacidade.
